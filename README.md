### Core Features
- Search for Attractions: Users can browse famous attractions in Taipei directly or search for specific attractions using keywords.
- Booking System: Allows users to book a day trip to their chosen attractions.
- Secure Payment: Integration with a credit card payment system for secure transactions.
- Responsive Web Design (RWD): Ensures optimal display and usability across a range of devices (desktop, tablet, mobile).
- Infinite Scroll and Image Carousel: Smooth, endless scrolling for attractions and dynamic image carousels to showcase attractions.
- Shopping Cart: A functional shopping cart system to manage selected attractions and bookings.

---
### Tech Stack
- Backend: Python with FastAPI framework for efficient, fast, and scalable backend development.
- Frontend: Responsive web design (RWD) with a focus on a seamless user experience.
- API Design: RESTful API architecture for structured, efficient communication between the client and server.
- Database: MySQL with connection pooling and parameterized queries to enhance performance and security.
- Version Control: Git/GitHub for collaborative development and version management.
- Payment Integration: TapPay third-party payment system for secure credit card transactions.
- UX Features: Infinite scroll loading for smoother browsing, and image carousel for an engaging presentation of attractions.
